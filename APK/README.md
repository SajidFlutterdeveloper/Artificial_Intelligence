# Build Artifacts

This folder is designated for compiled Android Application Packages (APKs).

## Instructions for Building
Since this environment is a development workspace, you can generate the latest APK by:
1. Opening the `Android_App` folder in **Android Studio**.
2. Going to **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. The generated file should be moved here for distribution.
